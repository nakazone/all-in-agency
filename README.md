# All In — Digital Agency

One-page bilingual (PT/EN) institutional site for **All In**, a digital agency specializing in websites, landing pages, and web applications.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4 (brand tokens via CSS custom properties)
- Framer Motion

## Getting started

Requires **Node.js 20+** (see `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
